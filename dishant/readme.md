// Step 1: Open Your Terminal

Open PowerShell, Command Prompt, or your terminal and make sure you are in the project folder:

powershell


cd "dishant/des2"
--------------------------------------------------------------------------------------

// Step 2: Check Node.js

Ensure Node.js is installed on your computer:

bash


node -v
npm -v
(Node.js v16+ or higher is recommended)

-----------------------------------------------------------------------------------------

// Step 3: Install Dependencies
Install the required packages (page-flip, etc.):

bash


npm install
-----------------------------------------------------------------------------------------
// Step 4: Start the Server

Run either of these commands:

bash


npm start
or

bash


node server.js

---------------------------------------------------------------------------------------

// Step 5: View the Application

The server will automatically open your default browser to:
http://localhost:3000
If port 3000 is already in use by another app, the server will automatically switch to http://localhost:3001.
To Stop the Server
Press Ctrl + C in your terminal window.
